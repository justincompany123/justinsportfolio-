# MyPersonalPortfolio

**Personal Portfolio Website Using Python and Flask**

## Project Description

MyPersonalPortfolio is a personal portfolio website developed using Python, Flask, HTML, and CSS. It showcases personal information, educational background, technical skills, projects, and contact details.

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Jinja2 Template Engine

## Project Structure

MyPersonalPortfolio/
- app.py
- requirements.txt
- README.txt
- templates/
  - index.html
- static/
  - style.css

## Requirements

- Python 3.10 or newer
- Visual Studio Code or another code editor
- A web browser

## Installation Instructions

1. Open the MyPersonalPortfolio folder in Visual Studio Code.
2. Open the integrated terminal.
3. Install the required packages by running:

   `py -m pip install -r requirements.txt`

## How to Run the Website

1. Open the terminal in the project folder.
2. Run the following command:

   `py app.py`

3. Open your web browser.
4. Visit:

   http://127.0.0.1:5000

Keep the terminal running while viewing the website.

## Website Features

- Personal introduction
- About Me section
- Educational background
- Technical skills
- Featured projects
- Contact information
- Responsive navigation
- Mobile-friendly design

## Customization

- Edit app.py to update personal information, skills, and projects.
- Edit templates/index.html to modify the webpage content and layout.
- Edit static/style.css to change colors, fonts, spacing, and visual design.
